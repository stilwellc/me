the line screen

One engine draws every header.

Each header is a field of vertical stripes, 6 px apart on a desk and 4 on a phone. The band is one still picture carved out of that field: where the picture has ink the stripes stop, and its ground stays stripes, so no box shows around it. A drawn mark is read as black and white. A photograph is read as luminance only and shades off through short dashes. No word is set in the band.

On load the stripes gather into the picture. Leaving a page scatters it, and the next page starts from the picture you left. Once it has settled the band stops drawing, and with reduced motion it is a still. One file, no dependencies.

Your picture never leaves this tab.

the build

There is no bundler, no template layer, and no client router. Each page carries its own markup, the shared stylesheet, and the two shared scripts; a cache-busting version on those files is the whole deployment story. Photographs ship with width and height and a small variant for phones. Social cards are rendered by a small page in the repository with the same line-screen code, once, and committed.

the threat model

The site runs code in your browser and reads data from other servers.

  • Visitors, the integrity of the pages, and the owner’s exact locationprotects
  • GitHub Pages serves every file; the repository is the source of truthboundary
  • JSON from api.github.com on the GitHub page
  • JSON from lectr.bid on the lectr study, where auction titles are untrusted text
  • three.js, served from this origin, on the wave page
  • binjgb (MIT), a Game Boy emulator compiled to WebAssembly, served from this origin, on the Stilwell Farms page
  • Content-Security-Policy with script-src 'self' and two hashed inline snippets: no other inline script and no third-party script runs. Only the Stilwell Farms page adds 'wasm-unsafe-eval', which lets the emulator’s WebAssembly compilecontrol
  • Every external string is escaped before it reaches the page
  • No cookies, no analytics, no third-party scripts
  • GitHub Pages sends no custom response headers, so no frame-ancestors and no Permissions-Policygap
  • Found something? /.well-known/security.txt, or GitHub private vulnerability reporting ↗report
