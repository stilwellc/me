Things I believe

  • Stop fixing bugs. Start removing bug classes.↗
  • Rules earn the right to block: a proven false-positive rate under 5% over a quarter, never straight to Block.↗
  • AI runs between rule evaluation and PR action, never in front of SAST.↗
  • Pattern presence is not reachability. A “Critical” behind a network ACL is not Critical.↗
  • Triage SLA matters more than bounty amount.↗
  • Build the safe primitive first, then write the rule blocking the unsafe one.↗
  • Find → triage → ticket is the wrong loop. Build → default → enforce is the right one.↗

One of the rules

rules:
  - id: ash-changeset-missing-actor
    languages: [elixir]
    severity: HIGH
    message: >
      Ash changeset or query executed without a valid `actor:` context.
      Nil or placeholder actors may bypass policy enforcement.
    patterns:
      - pattern-either:
          - pattern: Ash.Changeset.for_$ACTION($RESOURCE, $INPUT)
          - pattern: Ash.Query.for_read($RESOURCE, $ACTION)
      - pattern-not: Ash.Changeset.for_$ACTION($RESOURCE, $INPUT, actor: ($ACTOR & !nil))
      - pattern-not: Ash.Query.for_read($RESOURCE, $ACTION, actor: ($ACTOR & !nil))

Catches an Ash changeset or query built without a real actor:, which runs outside policy enforcement. From ash-changeset-missing-actor.yaml ↗, metadata trimmed.
