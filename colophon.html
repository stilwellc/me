Colophon · how this site is built

Static HTML.
No framework, no build step.

Seventeen pages, one stylesheet, two shared scripts, three font files, and a line-screen engine drawn on a canvas. It is served as static files from GitHub Pages, sets no cookies, and runs no analytics.

the line screen

One engine draws every header.

Each header is a grid of 4 px cells. A word is sampled into the grid as a mask; a picture is sampled at twice the resolution with local contrast and an edge channel, so photos become dashes and line drawings become squares. Empty cells get a filler dot, so every band is a full rectangle.

Each dot moves from a spot in the current image to one in the next, paired by angle around the center so paths don’t cross. Dots gather on load, explode and re-form on change, scatter on exit, and drift in a flow-field wind. One file, no dependencies.

Your picture stays in this tab and is discarded when the page closes.

the build

Hosting and build.

There is no bundler, no template layer, and no client router. Each page carries its own markup, the shared stylesheet, and the two shared scripts; a cache-busting version on those files is the whole deployment story. Photographs ship with width and height and a small variant for phones. Social cards are rendered by a small page in the repository with the same line-screen code, once, and committed.
